Rock vs Mine Prediction

A Machine Learning project that predicts whether an underwater object is a Rock or a Mine using sonar data.

Algorithm:
Logistic Regression

Technologies Used:
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Dataset:
The Sonar dataset contains 208 records with 60 numerical features.

R = Rock
M = Mine

Project Workflow:
1. Data loading and exploration
2. Data preprocessing
3. Train-test splitting
4. Model training using Logistic Regression
5. Model evaluation
6. Prediction on new input data

How to Run:
1. Clone this repository.
2. Install required libraries:
   pip install numpy pandas matplotlib seaborn scikit-learn
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Run all cells.
